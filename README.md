# Embermarch

Браузерная roguelite-тактическая RPG с русской и английской локализацией.

Один самодостаточный HTML-файл (`index.html`) — просто открой его в браузере, никаких зависимостей и сборки не требуется.

Играть онлайн: https://wiverhome.github.io/embermarch/

## Возможности
- Пошаговая тактическая боевая система (передний/задний ряд, цели, статусы)
- 8 героев с уникальными классами и способностями + создание собственных героев
  с распределением очков характеристик и выбором пассивки
- Прокачка героев внутри забега (опыт, уровни, выбор перков)
- Дерево улучшений между походами с ветками и капстоун-узлом
- Система реликвий и снаряжения, рюкзак — снятые вещи не теряются
- Цепочки событий на карте
- Испытание дня с полностью детерминированным сидом
- Достижения и журнал прошлых походов
- Процедурные звуковые эффекты (Web Audio API)
- Русская и английская локализация, тёмная и светлая темы интерфейса, мобильная вёрстка
