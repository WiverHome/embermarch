# Embermarch — идеи и задачи на будущее

Заметки для возврата позже. Записано 2026-09-27.

## Идеи для развития (не обязательные, но усилили бы игру)

### Глубина боя
- Позиции ряда сейчас почти не влияют на ИИ противников — можно сделать так, чтобы враги сознательно били по заднему ряду, если передний "открыт"
- Комбо-способности между героями (например, способность Кеста добивает оглушённую цель с бонусом) — сейчас синергии в основном через статусы, а не через прямые связки героев
- Элитные враги с уникальными модификаторами за слой (не только тир/статы, а особые правила боя)

### Прогрессия и повторяемость
- Дерево улучшений всё ещё плоский список — можно сделать реальные ветки (например, "Кости" открывают следующий тир только после покупки предыдущего)
- Мета-предметы/трофеи за конкретные достижения (не только угольки)
- Испытание дня сейчас определяет только карту — можно расширить до полностью детерминированного рана (тот же посев для всех событий/добычи), чтобы результаты игроков были по-настоящему сравнимы

### Контент
- Ещё пара архетипов врагов на верхние слои (сейчас тиры 1-4 переиспользуют один и тот же пул)
- Ивент-цепочки — событие на карте, которое аукается через несколько узлов дальше
- Кастомные герои (уже есть) — можно добавить им уникальные пассивки/облик наград

### UX
- Полноценная история боя с прокруткой/фильтром (сейчас лог короткий)
- Значок "новое" на разблокированных героях/реликвиях в Летописи
- Подтверждение перед выходом со страницы во время боя (защита от случайного закрытия вкладки)

## Обязательные к решению вещи (полноценность и надёжность)

### Обучение/подсказки
- Нет ни одного экрана-туториала или "правил игры" — игрок должен сам понять ряды, статусы, реликвии, откат способностей. Подсказки при наведении теперь есть, но это не заменяет краткий гайд при первом запуске

### Сохранность прогресса
- Всё хранится только в localStorage браузера — если игрок очистит кэш или сменит браузер, прогресс пропадёт без предупреждения. Экспорт/импорт кода уже есть, но игрока никто не подталкивает им пользоваться — стоит явно напомнить об этом при первом запуске или периодически

### Баланс
- Всё, что добавлено к 27.09.2026, прогонялось только через синтаксис-проверку и визуальные скриншоты, не через реальные игровые сессии — баланс новых способностей (оглушение, лайфстил Морвены, второй босс) не тестировался на реальных цифрах и может быть слишком сильным/слабым

### QA на крайних случаях
- Не проверены крайние ситуации: что будет, если оглушённый юнит умирает от горения в тот же ход; что если у героя 0 союзников в тылу для способности "Подсечка"; race condition в ачивках при одновременном срабатывании нескольких условий

### Доступность
- Нет поддержки клавиатуры для боевых действий (только мышь/тач), нет режима для дальтоников (статусы и элементы карты различаются в основном по цвету)

### Мобильные устройства
- Не проверялось на реальном тач-экране — zoom-трюк для масштабирования интерфейса на некоторых мобильных браузерах может вести себя непредсказуемо
