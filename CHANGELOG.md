# История разработки Embermarch

Все заметные изменения фиксируются здесь в хронологическом порядке (сверху — новее).
Формат свободный: что добавлено/изменено/исправлено в каждом проходе разработки.

## 2026-09-30 — Аккаунты и серверное сохранение прогресса (одиннадцатый проход)

### Добавлено
- **Реальные аккаунты игроков** — регистрация и вход по логину и паролю
  (без email, без восстановления пароля). Экран входа/регистрации теперь
  показывается первым, до титульного экрана.
- **Новый backend-сервис** `server/` (Node.js/Express + SQLite через
  `better-sqlite3`, хеширование паролей через `bcryptjs`, сессии — подписанные
  JWT-токены, rate limiting на `/api/register` и `/api/login`). Эндпоинты:
  `POST /api/register`, `POST /api/login`, `POST /api/logout`,
  `GET /api/progress`, `PUT /api/progress`, `GET /api/health`. Полная
  инструкция по развёртыванию на собственном сервере — в `server/DEPLOY.md`
  (systemd-юнит + nginx reverse proxy + Let's Encrypt под
  `embermarch.lapochka.online`).
- Игра обращается к API по адресу, заданному константой `API_BASE` в начале
  `<script>` (по умолчанию `https://embermarch.lapochka.online/api`).

### Изменено
- **`localStorage` больше не используется для прогресса.** Весь `META`
  (герои, улучшения, угольки, достижения, история походов, настройки,
  выбор биома/сложности) теперь хранится только на сервере и привязан к
  аккаунту. Каждый вызов `saveMeta()` теперь (с дебаунсом ~1.5 с) отправляет
  `PUT /api/progress` вместо записи в `localStorage`.
- Экран Летописи получил блок «Аккаунт» с именем текущего игрока и кнопкой
  выхода (`Log Out` / «Выйти из аккаунта»).
- `localStorage` по-прежнему используется только для двух вещей, не
  относящихся к серверному прогрессу: выбора языка интерфейса и временного
  состояния незавершённого забега на этом устройстве (`RUN`), чтобы страницу
  можно было случайно перезагрузить посреди боя без потери текущего забега.
  Сессионный токен входа **не** сохраняется в `localStorage` — он живёт
  только в памяти вкладки, поэтому обновление страницы всегда возвращает на
  экран входа (осознанный компромисс в пользу «прогресс только на сервере»).

### Известные ограничения / честно о рисках
- **Старый прогресс из `localStorage` не переносится.** Это осознанное
  решение по требованию — каждый игрок начинает с чистого листа на сервере.
- Пока владелец не развернёт `server/` по инструкции из `server/DEPLOY.md` и
  не настроит DNS + TLS для `embermarch.lapochka.online`, вход и регистрация
  на живом GitHub Pages сайте будут показывать ошибку сети — это ожидаемо,
  а не баг.
- **Версия-артефакт (Claude Artifact) с доступом к внешнему `fetch()` не
  была надёжно подтверждена работающей** — окружение артефакта, вероятно,
  ограничивает исходящие сетевые запросы к произвольным внешним хостам
  политикой песочницы (CSP), и это не удалось однозначно проверить вживую
  в рамках этого прохода (браузерная проверка упёрлась в необходимость
  входа в аккаунт claude.ai в браузере пользователя). На случай, если
  запрос к API блокируется, экран входа показывает понятное сообщение об
  ошибке сети вместо тихого зависания, с советом попробовать версию на
  GitHub Pages. Основной таргет фичи — сайт на `embermarch.lapochka.online` /
  GitHub Pages, а не артефакт.

## 2026-09-30 — Второй биом, модификаторы сложности, третья ветка улучшений (десятый проход)

### Добавлено
- **Биом «Морозный рубеж» («Frozen Reach»)** — второй, полностью параллельный
  биом похода наравне с «Пепельным походом»:
  - 6 новых обычных врагов: Инистый упырь, Ледяной лучник, Иневый волк,
    Морозная ведьма, Ледниковый рыцарь, Дух метели — свои пулы по каждому из
    4 ярусов сложности, свои SVG-иконки в том же минималистичном стиле, что
    и у остального бестиария.
  - 2 новых элитных врага (Страж вечной мерзлоты, Ледниковый тиран),
    заменяющие Раздутого ревенанта/Длань стража/Владыку пепла на элитных
    узлах карты в этом биоме.
  - Новый босс — **Ледяной государь** (The Rime Sovereign), с собственными
    способностями (ледяной коготь, ледниковый удар по ряду, хватка зимы,
    ярость-эксклюзивная «Вечная метель» по всему отряду) и SVG-иконкой.
  - Данные всех биомов сведены в единую структуру `BIOME_DEFS`; `buildEncounter()`
    и `startNewRun()` теперь читают пулы врагов/элит и список боссов из неё,
    а не из зашитых внутри функций таблиц, как раньше.
  - Выбор биома — на экране Летописи, рядом со сложностью похода; выбор
    запоминается в профиле игрока. Боевой экран и карта Морозного рубежа
    получают холодный синий акцент (`--accent`/`--accent-soft`) вместо
    тёплого пепельного — тот же принцип переменных темы, что и переключатель
    тёмной/светлой темы, только область действия — не весь сайт, а два
    экрана похода.
  - Испытание дня (Daily Challenge) всегда остаётся на «Пепельном походе» без
    модификаторов, чтобы все игроки в один день сражались с одинаковыми
    посеянными встречами.
- **Модификаторы сложности** — три независимых переключателя поверх обычного
  Ascension, каждый включается/выключается отдельно на Летописи:
  - **«Авангард элиты»** — при генерации карты 60% шанс превратить обычный
    бой в элитный на каждом слое, где элиты уже разрешены правилами карты.
  - **«Ранняя буря»** — пороги смены яруса сложности (`tierForLayer`) и рост
    характеристик врагов (`enemyScale`) сдвигаются вперёд по походу
    (умножение на ~0.78/1.18 соответственно), так что более сильные враги и
    их пулы приходят раньше, не трогая длину похода или позицию босса.
  - **«Разбитый оберег»** — герои получают на 15% больше урона в бою
    (`dmgCalc`), но золото за победу в бою (`onCombatWin`) увеличено на 20%.
  - Выбор сохраняется в `META.modifiers`, копируется в `RUN.modifiers` при
    старте похода; старые сохранения похода без этого поля получают
    безопасные значения по умолчанию при загрузке (`hydrateParty`).
- **Третья ветка дерева улучшений — критический удар**, на совершенно новой
  оси характеристик (до этого были только атака/скорость/защита/здоровье/
  золото): «Отточенное лезвие» (+3% шанс крита за уровень, 3 уровня) →
  «Смертельная точность» (+5% за уровень, 2 уровня) → капстоун «Зов смерти»
  (+8% шанс крита и +15% урон от крита). Шанс крита и бонусный множитель
  теперь хранятся на самом герое (`critBonus`/`critMultBonus`) и читаются в
  `dmgCalc()` наравне с существующим бонусом от реликвии «Счастливый клык».
- **Новая трёхшаговая цепочка событий**: «Пропавший разведчик» → «Долг
  разведчика» → «Возвращённый долг» — третья трёхшаговая цепочка в игре
  (после «Святилища» и «Старого поля боя»), с наградой в виде реликвии или
  золота на последнем шаге. Итого 13 цепочек событий.
- Новое достижение «Государь повержен» (+20 угольков) за победу над боссом
  Морозного рубежа — по тому же шаблону, что и для трёх боссов «Пепельного
  похода».

### Проверено
- Синтаксис (`node --check`) извлечённого скрипта — чисто.
- Playwright: 5 полных автопрогонов похода на автобоя (один — на Морозном
  рубеже со всеми тремя модификаторами сложности разом), 0 ошибок консоли,
  слои поражения бота 8–12/20 — в ожидаемом диапазоне, без регресса баланса.
- Отдельный прогон с зафиксированным `Math.random` подтвердил, что новая
  цепочка «Пропавший разведчик» → «Долг разведчика» → «Возвращённый долг»
  корректно срабатывает шаг за шагом без ошибок.
- Скриншоты: Летопись с выбором биома и включёнными модификаторами, Летопись
  с полностью выкупленной веткой крит. удара, бой в Морозном рубеже с новыми
  врагами и иконками, все три шага новой цепочки событий.

## 2026-09-30 — Визуал, ещё комбо, дерево улучшений (девятый проход)

### Добавлено
- **2 новые комбо-связки**, закрывающие оставшиеся пробелы между героями:
  Рассечение Брама оставляет всех задетых врагов «сбитыми с ног» — Удар
  когтем Дорана добивает их с бонусом +25% урона. Удар в спину или Убийство
  Кеста оставляет врага «кровоточащим» — Иссушающее касание или Похищение
  душ Морвены добивают его с бонусом +25% урона и усиленным лечением себя.
  Итого 8 комбо-связок.
- **Полноценный портрет кастомного героя**: вместо буквы/значка в кружке —
  композитный SVG-портрет (силуэт базового класса + выбранная эмблема
  маленьким значком в углу), тот же стиль, что и у готовых героев.
- **Ещё один уровень дерева улучшений**: новая базовая ветка «Пластины
  эгиды» (+1 к защите за уровень) с продолжением «Обряд бастиона» (+4 к
  защите за уровень), а над обоими капстоунами — новая высшая вершина
  «Наследие последнего уголька», требующая максимума «Стойкости авангарда»
  и «Обряда бастиона» и дающая +2 атака/+2 защита/+2 скорость/+10 макс.
  здоровья каждому герою.
- **Третий шаг у двух цепочек событий**: Святилище → Эхо оберега → «Полный
  оберег» (третий, завершающий шаг), Старое поле боя → Павший отряд →
  «Их последний дар» (третий, завершающий шаг). Итого 12 событий-цепочек
  вместо 10, две из них теперь трёхшаговые.
- **SVG-арт для всех врагов и боссов** взамен буквенных иконок в кружке —
  14 новых силуэтов (лучник, гончая, шаман, ревенант, рыцарь, банши,
  Владыка пепла, Полый Страж, Колосс и другие), в том же минималистичном
  стиле, что и у героев.
- **Визуальная обратная связь в бою**: всплывающие числа урона/лечения,
  тряска карточки при попадании, более сильная тряска и вспышка при крите,
  мягкое зелёное свечение при лечении, затухание карточки при смерти юнита,
  отдельная плашка «Комбо!» при срабатывании комбо-связки. Отключается
  вместе с общим переключателем анимаций.
- **Атмосфера фона**: лёгкие плавающие угольки-искры по всему экрану,
  фоновое затухающее свечение под картой похода, лавкой и привалом,
  мягкий радиальный подсвет во вражеской/союзной зоне боя вместо ровной
  заливки цветом.

### Исправлено
- **Список недавних походов в Летописи всегда показывал «/8»** вместо
  актуальной длины похода — забытое место с зашитым числом «8», не
  замеченное при переходе на 20-шаговый поход в седьмом проходе (карта,
  шапка похода и экраны победы/поражения были обновлены тогда же, этот
  список — пропущен). Теперь использует `TOTAL_STEPS`, как и везде.
- **Точность статистики «любимый герой»**: старые записи похода без
  сведений о составе отряда (`heroKeys`) не могут задним числом учитываться
  в подсчёте — это ограничение данных, а не баг сам по себе, но раньше это
  никак не отражалось на экране. Теперь подпись явно показывает, сколько
  походов реально учтено («X из Y походов с данными»), чтобы число не
  выглядело как процент от всех походов.

## 2026-09-28 — Комбо, цепочки, баланс похода (восьмой проход)

### Добавлено
- **6-я комбо-связка**: обжигающий выстрел Ашры (Всплеск углей) оставляет
  врага «обожжённым» — следующая дальняя атака Саэль (Выстрел, Пригвоздить,
  Смертельный глаз) по нему наносит +35% урона. Раздел «Комбо» в правилах
  игры обновлён.
- **3 новые цепочки событий** — закрыты все ранее известные события без
  продолжения:
  - Бродячий торговец → «Торговец возвращается» (более редкий товар за
    28 золота с шансом на реликвию, либо вежливый отказ).
  - Остывший костёр → «Тепло, что не гаснет» (согреть весь отряд лечением
    или обменять тлеющий уголёк на золото у следующей стоянки).
  - Старый учебный столб → «Наблюдающий ветеран» (спарринг с ветераном —
    урон герою взамен на увеличенный опыт, либо вежливый отказ с бонусом
    к защите).
  - Итого теперь 10 цепочек событий вместо 7.

### Исправлено
- **Баланс: удлинение похода до 20 шагов непреднамеренно утяжелило
  середину похода.** Формула `enemyScale()` считала рост силы врагов от
  «сырого» номера слоя (`li*0.045` и т.п.) — это было откалибровано под
  старый 7-слойный поход. После удлинения до 19 слоёв тот же номер слоя
  (например, 8) уже не означает «почти конец похода», а лежит лишь
  на середине — но формула по-прежнему накапливала почти столько же
  сложности, сколько раньше набегало к самому боссу. Наложившись на
  скачок пула врагов на новый ярус сложности (`tierForLayer`), это
  создавало резкий и неоправданный скачок трудности в середине похода.
  Обнаружено скриптованным автотестом (Playwright, серии полных проходов
  «в слепую»): все прогоны стабильно гибли около 8-го слоя из 20.
  Дополнительно `makeBossInstance()` был жёстко привязан к
  `enemyScale(7)` — наследие старого 7-слойного плана, из-за чего сам
  босс оказывался недостаточно усилен для нового 19-слойного похода.
  Исправлено: `enemyScale()` теперь считает силу врагов от доли
  пройденного пути (`li / TOTAL_MAP_LAYERS`), а не от номера слоя —
  рост сложности растягивается пропорционально длине похода вместо
  накопления с каждым лишним слоем. Константы подобраны так, чтобы
  сложность в точке босса (`li = TOTAL_MAP_LAYERS`) в точности совпадала
  со старой сложностью босса (той, что была при `li = 7`) — концовка
  похода осталась такой же тяжёлой, как и задумывалось, но путь к ней
  выровнен. `makeBossInstance()` также переведён на
  `enemyScale(TOTAL_MAP_LAYERS)`. Проверено повторными сериями Playwright:
  до исправления ни один прогон не проходил дальше 11/20 слоя; после
  исправления прогоны регулярно доходят до 12–15/20, встречая контент
  4-го яруса сложности, — ошибок в консоли не обнаружено ни в одном
  из ~16 прогнанных походов.

## 2026-09-28 — Карта и длина похода (седьмой проход)

### Изменено
- **Поход удлинён с 8 до 20 «шагов»** (19 слоёв карты вместо 7 + босс). План
  карты теперь строится программно (`buildLayerPlan()`, `TOTAL_MAP_LAYERS=19`)
  вместо ручного списка — это исключает повторение старого бага с целым
  слоем без боёв: привал теперь лишь один из вариантов смешанного пула
  последних слоёв, а не отдельный слой.
- Расчёт яруса врагов переведён на пропорциональные пороги (16%/42%/74% от
  длины похода) — устойчиво работает при любой длине похода.
- Все зашитые упоминания «8» как длины похода (шапка, экраны победы/поражения,
  Летопись, статистика) заменены на новую константу `TOTAL_STEPS` — везде
  показывается «N / 20».
- **Карта визуально увеличена**: SVG крупнее (320px высотой вместо 220px),
  больше расстояние между узлами, добавлены подписанные цветные полосы-ярусы
  («Ярус 1»…«Ярус 4»), узлы показывают простую иконку по типу вместо мелких
  трёхбуквенных подписей.

### Добавлено
- **Просмотр описания узла карты**: клик по любому узлу (не только доступному)
  открывает модальное окно с названием, иконкой и описанием типа точки; для
  доступного узла есть кнопка «Войти».

## 2026-09-27 — Контент и баланс (шестой проход)

### Добавлено
- Ещё одна комбо-связка: Пригвоздить Саэль оставляет врага «пригвождённым» —
  следующий базовый удар Брама, Дорана или Торвина наносит по нему +30% урона.
  Итого 5 комбо-связок.
- Две новые цепочки событий: Старое поле боя → «Павший отряд» (призраки погибшего
  отряда, можно почтить их память или обыскать стоянку), Заброшенная кузница →
  «Последний уголёк» (тлеющий уголёк из кузницы можно вплавить в оружие героя,
  который ковал, или обменять лудильщику). Итого 7 цепочек событий.

### Исправлено
- **Баланс: 4-й ярус врагов был недостижим.** Функция расчёта яруса сложности
  требовала как минимум 6-й слой карты, но по плану карты этот слой целиком
  состоит из привалов (без боёв). Из-за этого самые сильные обычные враги
  (рыцарь, банши, тлеющий крадец, заклинатель-фанатик) и элита «Владыка пепла»
  никогда не встречались игроку — мёртвый контент, а последний отрезок похода
  перед боссом был легче, чем задумано. Порог сдвинут на предпоследний слой,
  где ещё есть бои, — теперь этот контент действительно встречается.

## 2026-09-27 — Исправление мобильной вёрстки (критично)

### Исправлено
- **Не было тега `<meta name="viewport">`.** Из-за этого телефоны рендерили
  страницу как десктопную (виртуальная ширина ~980px) и просто уменьшали
  масштаб под размер экрана — все существующие мобильные `@media`-правила
  никогда не срабатывали. Именно поэтому мобильная версия была неудобной:
  крошечный текст, кнопки, по которым сложно попасть пальцем, нужно было
  постоянно щипком масштабировать экран. Добавлен `<meta charset="utf-8">`
  и `<meta name="viewport" content="width=device-width, initial-scale=1,
  viewport-fit=cover">` — теперь браузер использует реальную ширину экрана,
  и вся мобильная адаптация (раскладка боя в один столбец, увеличенные
  кнопки, обрезка зума) заработала так, как и было задумано.
